# Count Secured Password Variations

## Problem Description

In an Amazon security analysis task, two passwords have been generated, which may differ in length. One password is generated by a customer, and the other by an internal system. The customer wants to determine how many **secured variations** of the passwords exist, modulo $10^9 + 7$.

A **secured variation** is defined as a subsequence of the customer's password that is **lexicographically greater** than the system-generated password.

Formally:

* Let $s$ be the customer's password.
* Let $t$ be the system-generated password.

The task is to count how many subsequences of password $s$ are lexicographically greater than password $t$. Since the answer can be large, return the result modulo $10^9 + 7$.

---

## Definitions

### Subsequence

A subsequence is derived from the original string by deleting zero or more characters without changing the relative order of the remaining characters.

* *Example:* `"ac"` is a subsequence of `"abc"`, but `"ca"` is not.

### Lexicographically Greater

A string $x$ is considered lexicographically greater than a string $y$ if:

1. $x[i] > y[i]$ at the first position $i$ where $x$ and $y$ differ, or
2. $|x| > |y|$ and $y$ is a prefix of $x$ (where $|x|$ denotes the length of string $x$).

---

## Function Description

Complete the function `countSecuredStrings` in the editor.

### Parameters

* `string s`: The customer's password.
* `string t`: The system-generated password.

### Returns

* `int`: The number of subsequences of $s$ that are lexicographically greater than $t$, modulo $10^9 + 7$.

---

## Constraints

* $1 \le |s| \le 10^5$
* $1 \le |t| \le 100$
* Both $s$ and $t$ consist exclusively of lowercase English letters.

---

## Examples

### Example 1

* **Input:** `s = "aba"`, `t = "ab"`
* **Output:** `3`

#### Explanation

Let's look at all possible subsequences that can be obtained from $s = \text{"aba"}$ and compare them with $t = \text{"ab"}$:

| Subsequence Index Set | Subsequence String | Lexicographical Comparison with $t$ | Status |
| --- | --- | --- | --- |
| `[0]` | `"a"` | Smaller |  |
| `[1]` | `"b"` | Greater | Included (1) |
| `[2]` | `"a"` | Smaller |  |
| `[0, 1]` | `"ab"` | Equal |  |
| `[0, 2]` | `"aa"` | Smaller |  |
| `[1, 2]` | `"ba"` | Greater | Included (2) |
| `[0, 1, 2]` | `"aba"` | Greater | Included (3) |

From all possible subsequences, 3 are lexicographically smaller, 1 is equal, and 3 are greater than $t$. Hence, the answer is `3`.
